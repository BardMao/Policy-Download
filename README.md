# 法宝智抓 (PKULAW Batch Archiver) — 北大法宝 V6 批量下载扩展与沙盘测试台 (v3.3.0)

**法宝智抓 (PKULAW Batch Archiver)** 是一款专为 **北大法宝 V6 (`pkulaw.com`)** 设计的法律法规批量检索、全自动跨页勾选下载与人机验证协同工具。项目包含两部分：
1. **Edge / Chrome 浏览器扩展 (`PKULaw_Edge_Chrome_Extension.zip`, Manifest V3, v3.3.0)**：直接注入北大法宝真实网页底部，提供引导式批量下载控制条。
2. **Web 交互式沙盘与扩展构建器 (React + TypeScript + Vite)**：可视化模拟北大法宝检索与下载全流程，并支持在线自定义参数、一键打包生成最新的浏览器扩展 `.zip` 安装包。

---

## ✨ 核心功能特性 (v3.3.0)

* **真实浏览器环境无缝协同**：
  * 支持北大法宝账号密码登录、微信扫码登录、机构 IP 自动登录及 **CARSI 高校联盟认证登录**（完整继承浏览器 Cookie 与登录态）。
* **第 1 页弹窗选项录制 + 第 2 页起 1:1 状态同步**：
  * 第 1 页点击「开始下载」后，扩展自动勾选当页全部结果并呼出北大法宝原生「批量下载」弹窗。
  * 用户在第 1 页弹窗内选择所需格式（如 **纯文本 / 纯净版 / Word / PDF / 超文本**）并点击「确定」时，扩展自动录制真实点击 DOM 路径与弹窗内全部 `radio / checkbox` 勾选快照。
  * 从第 2 页起，扩展自动完成「翻页 → 全选当页法规 → 打开下载弹窗 → 1:1 还原第 1 页格式与复选框状态 → 点击确定触发下载」，彻底杜绝第 2 页起回退为默认《目录列表.xls》的问题。
* **防重复点击与 `.is-loading` 打包状态锁**：
  * 精准识别北大法宝 V6 弹窗确定按钮的 `.is-loading` / `disabled` 服务端打包等待状态，确保每一页严格只触发 **1 次** 压缩包下载，杜绝同一页产生 `(1)`、`(2)` 重复文件。
* **三档隔页等待速度预设（支持极速模式）**：
  * 内置 **⚡ 极速模式 (`0.5s ~ 1.2s`)**、**🚀 默认快速 (`1.0s ~ 2.0s`)** 与 **🛡️ 稳妥防封 (`3.0s ~ 5.0s`)** 三档隔页随机延迟，可在底部控制条「⚙ 下载设置」中随时切换。
* **智能人机验证（CAPTCHA）无感监测与自动恢复**：
  * 仅在视口中央真正出现滑块/安全验证浮层遮挡页面时自动暂停倒计时；用户在网页中滑过验证码后，扩展实时监测浮层消失并**全自动继续翻页下载**，无需额外点击确认按钮。
* **原始压缩包自动归档**：
  * 所有分页下载的原始 `.zip` 压缩包通过浏览器底层 `chrome.downloads.onDeterminingFilename` 自动归档至系统默认「下载 (Downloads)」目录下的指定子文件夹（默认 `PKULaw_Downloads/`），完成后支持一键打开下载文件夹。

## 🚀 浏览器扩展安装与使用指南 (Edge / Chrome)

### 第一步：获取并解压扩展包
1. 启动本项目前端页面，点击顶部导航栏右侧的 **「一键下载 Edge/Chrome 扩展包 (.zip)」**（或切换到「浏览器扩展导出」视图点击下载）。
2. 将下载得到的 `PKULaw_Edge_Chrome_Extension.zip` 解压到本地任意固定文件夹（例如 `D:\PKULaw_Extension`）。

### 第二步：在浏览器中加载扩展
1. **Microsoft Edge**：
   * 在地址栏输入 `edge://extensions` 并回车。
   * 开启左侧或右上角的 **「开发人员模式 (Developer mode)」**。
   * 点击 **「加载解压缩的扩展 (Load unpacked)」**，选择刚才解压出来的文件夹。
2. **Google Chrome**：
   * 在地址栏输入 `chrome://extensions` 并回车。
   * 开启右上角的 **「开发者模式 (Developer mode)」**。
   * 点击左上角 **「加载已解压的扩展程序 (Load unpacked)」**，选择解压后的文件夹。
3. *（版本更新提示）* 若此前已安装旧版本，解压覆盖原文件夹后，在扩展管理页点击扩展卡片上的 **「刷新/重新加载 (⟳)」** 按钮，确认版本号显示为 **`3.3.0`**。

### 第三步：在北大法宝网页中批量下载
1. 打开 [北大法宝高级检索页 (`https://www.pkulaw.com/advanced/law`)](https://www.pkulaw.com/advanced/law) 并完成登录（若页面底部显示 `步骤1/3`，登录成功后会自动推进，也可手动点击 **「我已完成登录，进入检索步骤 →」**）。
2. 在网页中设置检索条件并点击「检索」（建议将列表右上角每页条数设为 `20条/页` 或 `50条/页`）。
3. 点击页面底部扩展控制条的 **「刷新」** 核对总篇数与总页数，确认无误后点击 **「开始下载」**。
4. **第 1 页手动选定格式**：扩展会自动勾选第 1 页全部法规并弹出法宝「批量下载」窗口。请在弹窗中选择您需要的全文格式（如「纯文本」或「Word」）并点击弹窗内的 **「确定」**。
5. **第 2 页起全自动执行**：扩展将自动等待浏览器接收每页的 `.zip` 文件流，并按设定的随机间隔（默认 `1.0s ~ 2.0s`）自动翻页、全选、同步第 1 页格式并下载，直至所有分页全部完成。
6. 下载完成后，点击底部控制条的 **「📂 打开下载文件夹」** 即可直接查看所有下载好的原始压缩包。

## 🛠️ 本地开发与构建命令

### 环境要求
* Node.js `>= 18.0.0`
* npm 或 bun

### 常用命令

```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务器 (默认端口 3000)
npm run dev

# 3. 运行核心逻辑与扩展包生成单元测试

# 4. TypeScript 类型检查
npm run lint

# 5. 构建生产环境产物
npm run build
```

## 🔍 常见问题排查 (FAQ)

1. **点击「开始下载」后底部提示「请选择下载格式」，但页面上没看到法宝下载弹窗？**
   * 请点击底部控制条绿色的 **「重新勾选全选并打开格式框」** 按钮，或直接手动点击网页列表上方的法宝原生「批量下载」按钮打开弹窗。
2. **如何进一步加快翻页下载速度？**
   * 点击页面底部控制条右侧的 **「⚙ 下载设置」**，点击 **「⚡ 极速模式 (0.5s ~ 1.2s)」** 并保存，即可将隔页等待压缩至最低。
3. **遇到问题如何导出调试日志？**
   * 点击底部控制条右侧蓝色的 **「诊断与调试」** 按钮，扩展会自动将包含 DOM 识别状态、弹窗快照及事件追踪 (`eventTrace`) 的 JSON 诊断报告复制到剪贴板。
